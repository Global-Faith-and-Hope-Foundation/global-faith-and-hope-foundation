# Global Faith and Hope Foundation (GFHF) website

This is a static website prepared for GitHub Pages.

Files:
- index.html — Home
- about-us.html — About Us
- projects.html — Projects
- impact.html — Impact
- contact-us.html — Contact Us
- style.css — design
- script.js — mobile navigation

## Publish on GitHub Pages
1. Create/sign into a GitHub account.
2. Create a NEW public repository.
3. Upload all files in this folder to the repository root.
4. Open Settings → Pages.
5. Under Build and deployment, choose "Deploy from a branch".
6. Select the main branch and /(root), then Save.
7. GitHub will provide the public website address.

No paid hosting is required for this static site.
